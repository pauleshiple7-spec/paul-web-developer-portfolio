# Paul Eshiple — Web Developer Portfolio

A clean, responsive portfolio built with Next.js.

## Run locally

1. Open this folder in VS Code.
2. Open the terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open `http://localhost:3000`.

## Before publishing

Open `app/page.js` and replace:

- `your-email@example.com`
- GitHub URL
- LinkedIn URL

You can also update the project descriptions and add real demo/GitHub links when each project is ready.

## Important

The projects currently listed are presented as personal/demo projects, not client work. That is intentional and keeps the portfolio honest while still demonstrating your skills.
